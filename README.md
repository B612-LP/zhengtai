[项目现行入口](<选题/防晒霜-审美焦虑与消费信息信任/README.md>)：新版分享 HTML / 可编辑 PPTX、修订报告与待审核问卷。旧校赛包保留作历史模拟；新材料也未完成真人调查或人工定稿验收。

## 分工：按文件夹分地盘

| 目录 | 归属 |
|---|---|
| `选题/<提议人-主题>/` | 各自的选题地盘，平时只改自己的 |
| `资料/` | 共享资料，改前群里说一声 |
| 根目录说明文件（README/AGENTS） | 队长维护 |

- 改自己的地盘：直接提交，不用请示。
- 想改别人的：先在群里或 Issue 里说一声，别直接动。
- 每周任务：周一群里发"上周任务小结"，和这里的提交记录对得上就行。

## 验收：两层

1. **日常材料**（笔记、数据、草稿）：提交即留痕，每周小结时互相看，无需审批。
2. **要定稿的东西**（报告、PPT、问卷）：走 PR —— 改完开一个 PR，指定一个人看，同意后 merge＝验收通过；不满意就写评论、改完再提。

## 提交的三条路（按顺手程度选）

1. **让 AI 干（推荐）**：配好之后对 AI 说"把这个文件传到仓库""拉一下最新资料"就行。需要一次性配个 token，见下节。
2. **网页上传**：仓库页面 → Add file → Upload files → 拖文件 → 写一句说明 → Commit。
3. **网页编辑**：点开 `.md` 文件 → 铅笔图标 → 改完 Commit。

## 新人 10 分钟上手

1. [github.com](https://github.com) 注册（邮箱即可），用户名发给汽水，接受邀请。
2. 浏览器就能看和传文件（手机也可以）；想要"网盘体验"装个 GitHub Desktop。
3. **Agent 读写（可选，推荐）**：GitHub → Settings → Developer settings → Fine-grained tokens → 新建：只勾本仓库 + Contents 读写 → 把 token 配到你自己的 AI 工具里。
   - token 只发给自己的 AI 工具，**不要发到群里或给别人**；怀疑泄露就去原页面 Revoke，10 秒作废。

## 红线

- 模拟问卷数据只能放在带"模拟"标注的目录，不得与真实数据混放（比赛数据真实性要求）。
- 密码、秘钥、完整手机号等敏感信息不入库。
- 匿名评审版材料文件名不带姓名。
