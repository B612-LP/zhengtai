### 0.3 三条硬规矩（全员先记这三条，其余按需查）

1. **原始数据只增不改**：RAW 层一旦落盘，不许覆盖、不许手改；所有修正写进清洗层并留日志（12.1）。
2. **一个变量只装一个概念**：复合信息必须拆列（10.1 第 4 条），否则后面没法统计。
3. **不确定就填 `-99` 并写备注**，绝不猜。猜出来的数字比空缺更危险。

## 第 10 章 统一编码规范与数据字典

### 10.1 变量命名规则

**命名七条规则**：

| 序 | 规则 | 反例 → 正例 |
|---|---|---|
| 1 | 全大写英文＋下划线，不用中文、不用空格、不用驼峰 | `seatCount` → `OBS_SEAT_USED` |
| 2 | 格式＝`前缀_语义主体_后缀`；前缀标明数据集归属，后缀标明计量单位/类型 | `入座率` → `OBS_OCC_RATE` |
| 3 | 同一指标跨数据集**必须同名同码表**（如遮阴：静态 `SITE_SHADE_SCORE`、观察 `OBS_SHADE_SCORE`，码值完全一致） | 静态写 1–5、观察写 0–5 → 两处都用 0–5 |
| 4 | 一个变量只装一个概念；复合字段拆列 | `名称及类型` → `SITE_NAME` ＋ `SITE_TYPE_L1` ＋ `SITE_TYPE_L2` |
| 5 | 英文名一经确定，全组不得再用别名；修改必须升版本并在 10.5 登记 | — |
| 6 | **分类码值统一整数**；字母码只作展示标签/别名（决议 D-2） | 时段写 `T3` → 数据列填 `3`，展示可写 T3 |
| 7 | 编号（`_ID`）是标识符不是分类变量，**可以含字母段**（可读、可排序），如 `SZ-UC-PK-01` | — |

**数据集前缀表**（与蓝本第 2 章 D1–D6 数据源编号一一对应）：

| 前缀 | 数据集 | 采集方式 | 示例 | 三册别名（合并时换算） |
|---|---|---|---|---|
| `SITE_` | D2 空间清单（静态属性，一次核实长期有效） | 线上查证＋线下踏勘 | `SITE_ID`、`SITE_SEAT_CNT` | A 册 `SPC_*`、B 册 `SPACE_*` → 一律换 `SITE_` |
| `OBS_` | D3 线下观察（同一空间多轮次） | 现场记录表 | `OBS_OCC_RATE`、`OBS_SHADE_SCORE` | A 册 `OBS_*`（大部分同名） |
| `SUR_` | D1 预调查问卷 | 问卷星/纸质 | `SUR_IMP_SEAT`、`SUR_SAT_SHADE` | A 册 `SUR_*`（权威源） |
| `INT_` | D4 访谈 | 半结构化＋转写 | `INT_EVENT`、`INT_CAUSE_3` | A 册 `INT_*` |
| `GOV_` | D5 政府公开/客观数据 | 平台取数 | `GOV_INVEST_CNY`、`GOV_SRC_NO` | B 册数据源编号 `S01–S27` → 填 `GOV_SRC_NO` |
| `META_` | 元数据与质量标记 | 流程自动/人工 | `META_QC_FLAG`、`META_VER` | A/B 册散落的采集人/版本字段 → 归此 |
| `EVD_` / `CARD_` | D6 归因卡（分析层，B 册产出） | 由清洗层派生 | `EVD_LEVEL`、`CARD_ID` | B 册 `EVIDENCE_LEVEL`、`CARD_ID` → 收口 |

> **成因码不再是变量前缀**：成因是"码值 1–5"，不是前缀。变量名里体现成因的只有 `INT_CAUSE_1..5`（0/1 标记列）与 `GOV_CAUSE_CODE`。v1.0 的 `CAUSE_1..5` 前缀写法作废。

**后缀（单位/类型）字典**：

| 后缀 | 含义 | 数据类型/格式 | 示例 |
|---|---|---|---|
| `_ID` | 编号 | 文本 | `SITE_ID` |
| `_CNT` | 计数（人、个、处） | 整数 | `OBS_SEAT_TOTAL` |
| `_SUM` | 合计 | 数值 | `SUR_CNT` |
| `_RATE` | 比率，0–1，保留 2 位小数 | 小数 | `OBS_OCC_RATE = 0.85` |
| `_PCT` | 百分数，0–100，保留 1 位（选填，如遮阴覆盖率） | 小数 | `SITE_SHADE_PCT = 35.0` |
| `_MIN` | 时长，分钟 | 整数 | `SITE_WALK_MIN`、`INT_DUR_MIN` |
| `_M2` | 面积，㎡ | 小数 1 位 | `SITE_AREA_M2` |
| `_M` | 距离/长度，米 | 整数 | `SITE_DIST_M` |
| `_C` | 温度，℃ | 小数 1 位 | `OBS_TEMP_C` |
| `_CNY` | 金额，元 | 数值 | `GOV_INVEST_CNY` |
| `_SEC` | 时长，秒 | 整数 | `SUR_DURATION_SEC` |
| `_DATE` | 日期 `YYYY-MM-DD` | 文本 | `SITE_VERIFY_DATE` |
| `_TIME` | 时刻 `HH:MM`（24 小时制） | 文本 | `SITE_OPEN_TIME` |
| `_CODE` | 单值分类码（查 10.2） | 整数 | `GOV_CAUSE_CODE` |
| `_L1` / `_L2` | 两级分类的层级 | 整数 | `SITE_TYPE_L1` |
| `_1`~`_5` | 多选/矩阵拆列的第 N 项 | 整数 | `SITE_LIMIT_CODE_1`、`SUR_IMP_SEAT` |
| `_DESC` | 开放文本（≤100 字） | 文本 | `SITE_LIMIT_DESC` |
| `_YN` | 是否，1 是 / 0 否 | 整数 | `INT_CONSENT_YN` |
| `_SRC` | 来源说明/URL | 文本 | `SITE_SRC_URL`、`GOV_SRC_URL` |
| `_RAW` / `_CLN` | 原始值 / 清洗后值（异常改值成对保留） | 同原字段 | `OBS_OCC_RATE_RAW` / `OBS_OCC_RATE_CLN` |

| 编号 | 规则 | 示例 |

### 10.3 缺失值与特殊值代码

**核心三个（必用；数字型与整数码列一律用）**：

| 码 | 含义 | 什么时候用 | 举例 |
|---|---|---|---|
| `-99` | 未采集 | 漏填、设备失败、时间不够没记 | 忘了数座椅 → `SITE_SEAT_CNT = -99` |
| `-98` | 不适用 | 逻辑上不存在该值 | 非学生填年级 → `SUR_GRADE_CODE = -98` |
| `-97` | 拒答 | 受访者/被访方明确拒绝 | 拒绝说年龄 → `SUR_AGE = -97` |

**可选扩展（T-05 待拍板）**：

| 码 | 含义 | 适用 |
|---|---|---|
| `-96` | 无法判断（观察者不确定，非未采集） | `OBS_SHADE_SCORE = -96`＋备注说明哪一点不确定 |

**多选码列规则（`_1.._3`）**：

- 按占比/重要性排序填在前几列，未填满的列填 `-98`（不适用）。
- 一个"互斥码"（如"无"NONE、"无限制"0）与其他码不能同时出现。
- 同一码不得重复出现在两列。

**填写纪律**：

1. 文本列缺失留**空单元格**，不写「无」「不知道」「/」「—」；"无"用码 `0` 或 NONE 类码表达。
2. **"0"与"-99"必须分清**：某空间确实没有座椅记 `0`；没数记 `-99`。
3. 任何 `-9x` 值必须在同行 `META_QC_NOTE` 或 `_DESC` 列写一句原因。
4. 缺失比例阈值：单字段缺失 >20% 在周报预警；>50% 该字段不进入分析（12.4）。

### 10.4 单位统一与派生公式

| 项目 | 统一单位/格式 | 说明 |
|---|---|---|
| 面积 | ㎡（`_M2`，1 位小数） | 1 亩≈666.7㎡，1 公顷＝10000㎡ |
| 距离/长度 | 米（`_M`，整数） | 不写"很近"；步行时间另填 `_MIN`（分钟） |
| 时长 | 分钟（`_MIN`）；答题时长用秒（`_SEC`） | 不写"半小时" |
| 比率 | 0–1，2 位小数（`_RATE`） | 入座率 `0.85`，不写 `85%` |
| 百分数 | 0–100，1 位（`_PCT`，选填） | 遮阴覆盖百分比 `35.0` |
| 人数 | 人（`_CNT`，整数） | 站立人数另列 `OBS_STAND_CNT` |
| 金额 | 元（`_CNY`） | 政府文件写"万元/亿元"时换算并在 `_DESC` 留原口径 |
| 日期/时间 | `YYYY-MM-DD` / `HH:MM` 24 小时制 | 2026-10-27 / 18:30 |
| 经纬度 | WGS84，小数 5–6 位 | 做地图站时统一转 GCJ-02，原始表不动 |
| 座椅折算 | 长凳按 **0.6 m/人** | 1.8 m 长凳＝3 人（A 册 §1.2） |
| 照片 | `PHOTO-<SITE_ID>-<YYYYMMDD>-<2 位序号>.jpg` | 存 `05_现场影像/`；A 册 `P-日期-序号` 为别名 |

**核心派生公式（一次写死，脚本实现，不手填）**：

```
# 1) 入座率（主指标，三次扫描平均，分母扣不可用座位）
OBS_OCC_AVG     = (OBS_OCC_1 + OBS_OCC_2 + OBS_OCC_3) / 3        # 平均就座人数，保留 1 位
OBS_SEAT_USABLE = OBS_SEAT_TOTAL − OBS_SEAT_UNAVAIL              # 可用座位数
OBS_OCC_RATE    = OBS_OCC_AVG / OBS_SEAT_USABLE                  # 0–1，保留 2 位

# 2) 座椅合计（正式＋非正式两列并存，T-03 关账）
SITE_SEAT_CNT   = SITE_SEAT_FORMAL_CNT + SITE_SEAT_INFORMAL_CNT  # 入座率分母用合计
# 敏感性检验：只看正式座椅时，分母用 OBS_SEAT_FORMAL_USABLE（= 正式座椅 − 不可用）

# 3) 供需缺口（问卷量表 0–5 同尺度）
GAP_<维>        = SUR_IMP_<维> − SUR_SAT_<维>                     # 正值＝重视但现状不够

# 4) 派生控制变量
OBS_HOLIDAY_YN  = (OBS_DAY_TYPE == 3)
OBS_HEAT_YN     = (OBS_TEMP_C >= 33)

# 5) 年龄段归并（6 档采集 → 4 组分析；单组有效样本 <30 时并 3 组）
SUR_AGE_GRP4    = 1 if SUR_AGE == 1
                = 2 if SUR_AGE in (2, 3)
                = 3 if SUR_AGE in (4, 5)
                = 4 if SUR_AGE == 6
# 3 组版：18–22（码 1）/ 23–45（码 2–5）/ 46+（码 6）；报告写明用哪一档
```

**入座率口径纪律**：

- 分子＝**三次扫描**（每 10 分钟扫 1 次、每次 5 分钟内扫完）的算术平均；三次之间不换观察位（A 册 §2.1）。
- 计入就座：臀部接触座位面（含台阶、花坛边、地上垫子）；一人占多座按**实际占座数**计入。
- 不计入：站立、倚靠、蹲、儿童在座椅上玩耍、外卖/快递临时搁放。
- 空位被私人物品占但人在旁 → 算已就座；被单车/杂物占且无人在旁 → 不入分子，计入 `OBS_SEAT_UNAVAIL`。
- 分母为 0 或未知 → `-98` / `-99`，**不要算成 0**。
- 入座率分档（分析口径，仅描述不裁决）：<30% 闲置｜30–60% 一般｜60–85% 较高｜≥85% 饱和。

## 第 12 章 清洗与质控规则

### 12.1 三层数据与清洗总原则

| 层 | 位置 | 规则 |
|---|---|---|
| RAW 原始层 | `01_原始数据/` | 只增不改；问卷星原始导出、纸质拍照、录音原文件、观察手记扫描件都在这里；命名带 `_raw` |
| CLEAN 清洗层 | `02_清洗数据/` | 脚本从 RAW 生成，可重复运行；异常值保留 `_RAW` 与 `_CLN` 两列 |
| ANALYSIS 分析层 | `03_分析数据/` | 由 CLEAN 派生，只保留分析用字段；任何汇总表都能回指到行级数据；D6 归因卡在此层 |

**五条清洗原则**：

1. **不覆盖原始值**：改值必须成对出现 `X_RAW` / `X_CLN`；只改 `_CLN`。
2. **规则先写后跑**：每条清洗规则先写进 `清洗规则.md`（编号 `R01`…），再写进脚本；脚本头部注释规则编号。
3. **一次脚本、可复现**：清洗只通过脚本执行，禁止手工在 Excel 里删行；脚本与输出同版本号。
4. **每个删除都有理由**：删行/删列必须在 `清洗日志.csv` 记一行（时间、操作、影响行数、理由、操作人）。
5. **QC 标记不删除**：可疑但不该死的记录标 `META_QC_FLAG`，不直接删；分析时按标记筛选。

### 12.2 去重规则

| 对象 | 唯一键 | 重复判定 | 动作 |
|---|---|---|---|
| 空间清单 | `SITE_ID` | 同一 `SITE_ID` 出现多行 | 合并为一行；冲突字段取**核实日期更新**的一条，旧的写入 `SITE_NOTE` |
| 空间清单（实体重复） | `SITE_NAME`＋`SITE_LNG`/`SITE_LAT` | 同一空间被两人各建一档（如"中心公园"/"大学城公园"） | 保留编号小的，另一条并入并登记别名 |
| 观察记录 | `SITE_ID`＋`OBS_DATE`＋`OBS_TIME_SLOT` | 三项完全相同 | 保留先入库的一条；两人同时段各记一份 → 取两次 `OBS_OCC_AVG` 均值，差异写入 `OBS_NOTE`；差异 >10 个百分点按 12.5 重数 |
| 问卷 | `SUR_SRC_ID` | 完全相同 | 删后者 |
| 问卷（疑似重复人） | `SUR_CHANNEL`＋`SUR_DURATION_SEC`＋关键人口字段＋提交间隔 | 同设备/同 IP 短时间多份且答题时长异常短 | **不直接删**，标 `META_QC_FLAG=3`，回访确认后人工决定去留 |
| 访谈 | `INT_ID`＋`INT_EVENT_NO` | 同一事件多行 | 保留一条，重复内容并入 `INT_QUOTE` |
| 政府数据 | `GOV_METRIC`＋`GOV_YEAR`＋`GOV_GEO` | 三键相同 | 保留官方原始来源；口径不同的两条并列，用 `GOV_NOTE` 区分 |

**纸质问卷录入口径**：一纸一录，录完第二人抽 20% 复核；两份录入不一致的字段以纸质原件为准。

### 12.3 异常值规则与处理动作

**异常值五档处理**（对应 `META_QC_FLAG`）：

| 标记值 | 含义 | 处理 |
|---|---|---|
| 0 | 通过 | 正常进入分析 |
| 1 | 待核 | 保留，不参与统计，等复核 |
| 2 | 已改值 | `_CLN` 已修正，保留 `_RAW`，记日志 |
| 3 | 异常保留 | 复核确认是真实极端值（非错误），分析时单独说明 |
| 4 | 作废 | 整条不能用（如未知情同意、明显造假），保留行但排除 |

**字段级合理区间与触发动作**：

| 字段 | 合理区间 | 超界动作 |
|---|---|---|
| `OBS_OCC_RATE` | 0–1 | >1 → 先查分母（是否漏计新增座椅/站位）与分子（是否把站立/走动的人算进去）；**一律 QC_FLAG=1，当日重数一次**，不得直接截断为 1 |
| `OBS_OCC_1/2/3` | 0 ≤ 值 ≤ `OBS_SEAT_TOTAL` | 三次扫描**极差 > 均值的 30%** → 补第 4 次扫描取 4 次均值；仍不稳则 QC_FLAG=1 |
| `OBS_SEAT_UNAVAIL` | 0–`OBS_SEAT_TOTAL` | 超过总数 → 录入错误 |
| `OBS_SEAT_USABLE` | ≥1 | =0 → `OBS_OCC_RATE=-98`（可用座位为零不能算率） |
| `OBS_SEAT_TOTAL` / `SITE_SEAT_CNT` | 0–500 | 超界先核单位与手误（多打一个 0）；两者不一致且 `OBS_NOTE` 无说明 → QC_FLAG=1 |
| `SITE_SEAT_FORMAL_CNT`＋`SITE_SEAT_INFORMAL_CNT` | 应等于 `SITE_SEAT_CNT` | 不等 → 计算列错误，重算 |
| `*_SHADE_SCORE` / `*_AC_SCORE` / `OBS_NOISE_SCORE` / `OBS_CLEAN_SCORE` | 0–5 整数 | 超界（6、10）→ 录入错误 |
| `SITE_SHADE_PCT` | 0–100 | 超界 → 录入错误 |
| `OBS_TEMP_C` | -10–45 | 超界 → 手误或用了预报值 |
| `SITE_WALK_MIN` | 1–40 | >40 → 确认是否填了距离而非分钟 |
| `SUR_AGE` | 码 1–6（表 10，6 档；线下补记 0） | 超界（7、10、18 等）→ 录入错误；若误填了出生年份 → 按题面重编码或 QC_FLAG=1 |
| `SUR_DURATION_SEC` | ≥60 秒（A 册口径） | <60 秒 → 判无效（QC_FLAG=4）；60–90 秒 → QC_FLAG=3 待回访 |
| `SUR_IMP_*` / `SUR_SAT_*` | 0–5 整数 | 超界（6、10）→ 按题面重编码或 QC_FLAG=1；**全量表同一答案** → 判无效（QC_FLAG=4） |
| `SITE_OPEN_TIME` / `CLOSE_TIME` | 合法 HH:MM 且 开<关 | 关≤开（跨夜）→ 在 `SITE_NOTE` 说明，不自动判错 |
| `GOV_VALUE` | ≥0 | 负数→口径问题（如净投资），必须写 `GOV_NOTE` |
| 逻辑矛盾 | — | 例：`SUR_OCC=1`（在校学生）却 `SUR_AGE=6`（46+）；`SUR_IS_STUDENT=1` 却职业=退休；`OBS_DAY_TYPE=1` 但日期是周六；`SITE_ENTRY_FREE=1` 却 `SITE_COST=2` → QC_FLAG=1 |

**改值纪律**：改值必须同时满足"有证据（回访记录/重数记录/纸质原件）＋两人确认"；只改 `_CLN` 并写日志，禁止直接改 RAW。

### 12.4 缺失值处理

| 缺失比例（单字段） | 处理 |
|---|---|
| ≤5% | 直接分析，报告中说明缺失量 |
| 5%–20% | 分析前在周报预警，尽量补采 |
| 20%–50% | 该字段进入"部分可用"，任何基于它的结论必须标注样本量 |
| >50% | 该字段不进入分析；在 10.5 字典里标"采集失败，v2 重新设计" |

**不许做的事**：用均值/众数填补后当作真实值报出；用 AI 生成/补全缺失值；把 `-9x` 当 0 参与计算。

### 12.5 双人核对与抽样复核流程

**A. 现场双人核对（观察环节，每轮必做）**

1. 两人同时到场、各持一份空白记录表，**同一时点各自独立完成三次扫描**。
2. 两人独立填表，填完再对；不许一人报数一人抄。
3. 比对 `OBS_OCC_RATE`（换算成百分点）：差值 ≤5 个百分点 → 记两人均值，QC_FLAG=0；5–10 个百分点 → 重做三次扫描一次；>10 个百分点 → 重数后仍不一致，取两人均值并 QC_FLAG=1，备注写两人读数。
4. `OBS_SEAT_TOTAL`、`OBS_SEAT_UNAVAIL`、`*_SHADE_SCORE`、`*_AC_SCORE` 等计数/主观类字段：不一致以现场复核确认为准，记 QC_FLAG=1 直到确认。
5. **0–5 锚定表先 2 人试测 1 个空间校准**（A 册 P8）：两人分差 >1 分即回炉重定锚定语，再开始正式观察。
6. 照片各自拍，选清晰的那张进表，另一张仍归档。

**B. 抽样复核（全流程，采集负责人执行）**

| 环节 | 抽检比例 | 抽检人 | 判定通过线 | 不通过动作 |
|---|---|---|---|---|
| 观察记录 | 每空间 ≥1 轮（约 10%）独立重核 | 非本空间记录人 | 关键字段（入座率/座数/遮阴分/空调分）一致率 ≥95% | <90% 该空间全量回看；90%–95% 再抽 10% |
| 纸质问卷录入 | ≥20% | 非录入人 | 逐字段一致率 ≥98% | 全量重录 |
| 问卷逻辑与异常 | 全部问卷跑规则脚本＋人工抽 10% 看开放题 | 问卷负责人 | 剔除率 ≤10% | 超限回查问卷设计 |
| 访谈转写 | 每份抽 30% 段落对照音频 | 非转写人 | 关键数字/时间/因果表述无错 | 全份回听；引用原话段落 100% 核对 |
| 访谈编码（`INT_CAUSE_*`） | ≥20% 双人独立编码 | 第二编码人 | 编码一致率 ≥80%（Cohen's κ 另算） | 不一致处讨论统一并修订编码说明 |
| 限制码判定（`SITE_LIMIT_CODE_*`） | 每空间 100% 第二人复判 | 非判定人 | 码值一致 | 不一致回现场确认 |
| 政府数据 | 100% 复查链接与年份口径 | 取数人以外 1 人 | 可回溯、口径一致 | 重取 |

**C. 复核留痕**：每次复核在 `质控日志.csv` 记一行：`日期, 环节, 抽检范围, 抽检人, 一致率, 结论(通过/回看/重做), 处理记录路径`。

**D. 交付闸门**：数据交给分析/建站前必须过四道——

1. 主键唯一、无重复（脚本查）。
2. 所有 `META_QC_FLAG=1` 已清零或转为 2/3/4。
3. 派生列（入座率、GAP、可用座位数）全部由脚本重算，与手填值一致。
4. 数据字典与本分册 10.5 版本一致（`META_VER` 对得上）。

## 第 13 章 AI 使用边界与披露

> 依据：小组共识"备赛引入 AI 赋能，全过程人工审核把关"；卢雨婷"数据 → AI 归因 → 商业落地"链路；B 册 §0.4-6 与 §9.3 AI 归因规范；正大杯允许报告附录含 AI 使用说明（第十六届广东省赛口径，第十七届以正式通知为准）。

### 13.1 使用原则

1. **AI 是工具不是作者**：AI 负责速度（转写、归类、初筛、原型），人负责判断（改写、确认、结论）。
2. **可回溯**：每次用 AI 都记进 13.4 使用记录表，能回答"这段文字/这个数字是怎么来的"。
3. **不生成事实**：AI 不得补全缺失数据、不得编造受访者原话、不得生成没做过的观察记录。
4. **不喂敏感信息**：受访者姓名/学号/手机号/可识别照片不进入任何公共或境外模型；访谈先脱敏成 `INT_LABEL`。
5. **结论双保险**：任何 AI 结论必须能指回数据证据行（`EVD_LEVEL`＋`CARD_ID`），且有 `REVIEW_STATUS` 人工确认。

### 13.2 分环节允许清单

| 环节 | 用不用 AI | 具体做法 | 人工必须做的 |
|---|---|---|---|
| 访谈录音转写 | ✅ 用 | 平台/大模型转写，输出存 `..._v1_ai.md`，`INT_TRANS_SRC=2/3` | **逐份通读校对**：数字、时间、因果表述、行业词；引用原话段落 100% 对照音频 |
| 访谈文本归类/主题编码 | ✅ 用（只作建议） | AI 给出主题标签与成因码 1–5 建议，人工采纳/改判 | 编码 ≥20% 双人独立复核，一致率 ≥80%；`INT_CAUSE_*` 最终由人填 |
| 问卷开放题清洗 | ✅ 用（只作粗筛） | AI 把开放题归成若干类并标出疑似无效/敷衍答案 | 抽 10% 人工核对；删除/作废决定由人做，标 `META_QC_FLAG` |
| 问卷异常检测 | ✅ 用 | AI 辅助写规则/脚本检查逻辑矛盾、时长异常 | 规则由人确认；误判需人工回访确认 |
| 数据清洗脚本 | ✅ 用 | AI 生成 pandas 脚本草稿 | 人跑一遍、抽检 10 行、确认不覆盖 RAW |
| AI 归因（成因分析） | ✅ 用（假设生成器） | AI 基于清洗后数据提出成因候选与证据线索，输出 `AI_METHOD` 标记 | **每条归因至少 2 条来源独立证据＋人工判定**（B 册 §0.3），无证据的不进报告；`REVIEW_STATUS` 交付前必须 2/3 |
| 报告文字润色 | ✅ 用 | 语法/结构建议 | 数字、口径、引用必须人核；不得让 AI 改数据 |
| 独立站原型/前端 | ✅ 用 | 页面结构、交互、样式生成 | 数据接入前人工核对字段与数值；站内数据必须来自清洗层 |
| 政府数据检索 | ✅ 用（辅助） | AI 找公开数据线索 | **链接与年份口径 100% 人工打开复核**，AI 给的数字不得直接采用 |
| 图表生成 | ✅ 用 | 代码生成图表 | 人核坐标轴、单位、样本量标注 |
| 观察记录填写 | ❌ 不用 | — | 现场必须人看人数，AI 不得生成观察数据 |
| 限制码判定 | ❌ 不用 | — | 现场踏勘者依事实判码 |
| 结论定稿 | ❌ 不用 | — | 结论由人写、人签字 |

### 13.3 禁止清单（红线）

1. 用 AI 编造或补全任何字段值（含"合理推测"入座率）。
2. 把 AI 生成的句子当作受访者原话放进报告。
3. 将含姓名、学号、手机号、可识别住址/单位的信息上传到 AI 工具。
4. 把 AI 归因结果直接写成报告结论而不给数据证据。
5. 在报告中隐瞒 AI 使用（评委更在意是否说清楚，而不是用不用）。
6. 用 AI 伪造政府数据口径或年份。

   （3）所有 AI 生成的清洗脚本经人工复核并在原始数据副本上运行，原始数据未被修改；
   （4）成因分析结论均由成员结合至少两条来源独立的证据判定，报告中每条归因可回溯到具体数据表与字段；
   （5）AI 未参与数据采集过程，未生成或补全任何原始数据。
4. 未使用 AI 的环节：现场观察记录、空间限制码判定、问卷与访谈实施、原始数据录入、最终结论撰写。
5. 使用记录：完整逐条记录见随报告提交的《AI 使用记录表》（共 N 条）。
