# 02 调查方案设计：防晒霜信息信任调查

> **本周演练设计，不是正式定题或发放许可；未实际发放问卷。** 当前审题底稿为[06-问卷v1.1-预调研候选版](<06-问卷v1.1-预调研候选版.md>)；[旧06](<06-问卷终稿.md>)只保留历史。与历史[00计划](<00-全流程方案与执行计划.md>)、[07报告](<07-分析报告v1.md>)不一致处，研究设计以本次候选口径供人工审核，不代表其他历史材料已更新。

## 一、调查目的

承接[01-市场调查概述](<01-市场调查概述.md>)：描述信息来源信任（RQ1），考察日晒相关外貌担忧和理解门槛与信任的关联（RQ2），了解自报选择线索（RQ3）；供给侧宣称核查（RQ4）仅在可取得证据时补充。不把横截面自报关联写成因果，也不把注册资料当作个体适用/真实功效保证。

## 二、调查对象与范围

- **目标资格**：自愿同意、18–35岁、过去6个月参与选择购买或使用过防晒霜/乳、喷雾。S1年龄段18–24、25–30、31–35无重叠；其他年龄及拒答结束。
- **核心购买样本**：S2=①，本人参与过产品选择，付款者可以是他人；只有这类样本进入B/C/D/G及H1–H5购买分析。
- **仅使用补充样本**：S2=②，没有参与购买选择但使用过；只答A/E/F/Q1/H2。不得强答购买题，不与购买者混用分母。仅代付款/代购、未参与选择且未使用者等退出。
- **地域与触达**：深圳为主，线上扩散不限地区，A3记录地区；学生为主、年轻职场为辅，现实属于非概率便利/滚雪球抽样，不代表全国18–35岁消费者。
- **肤质/敏感**：A5基础肤质与A6敏感自报独立，不把敏感当作油/干肤质类别，不作医学诊断。

## 三、指标—题号—假设映射

完整题文、分流、编码、缺失与计分规则见[候选问卷第二节](<06-问卷v1.1-预调研候选版.md>)。

| 问题/假设 | 对应测量 | 本周最小分析与边界 |
|---|---|---|
| RQ1 信息信任结构 | C1–3专业信息P；C4–6品牌A；C7–9博主B；C10–12平台L；C13–15熟人R | 五来源分别描述，朋友不混入博主/平台，平台维度异质时逐题报告，不强合总分 |
| H1a 专业信息信任是否高于博主信任 | P与B，同一购买者 | 同构念配对差值；初检可用后探索配对t或Wilcoxon，报告效应量与不确定性 |
| H1b 博主使用是否高于专业信息使用 | B2-3与B2-1，同一购买者 | 同构念频率比较，序数描述/Wilcoxon；不得将信任分与频率分直接相减或t检验 |
| H1补充 来源排序不一致 | 对齐五来源C均分与B2五行 | 并列名次保留，只描述不一致人数/比例，不叫真实行为缺口验证 |
| H2 外貌担忧与信任关联 | E1–3均分与B、A分别相关 | 预期正向，Spearman；非营销导致焦虑的证据 |
| H3 理解门槛与信任关联 | F1–3均分与P（预期负向）、B（预期正向） | F高分=更困难；Spearman，不沿用旧模拟脚本“越高越懂”的方向 |
| H4降为探索问题 | G1/G2统一89元与259元、50mL、SPF50+ PA++++比较 | 两价情境全员一致，功效未知；报告自报判断/选择比例与信息不足选项，不做三档单调趋势或因果实验 |
| H5探索群体差异 | A1/A2/A5/A6分别与C各维度 | 先分层描述，稀疏组不检验；不扩展性别×身份×肤质三重模型 |
| RQ3/定性补充 | B1渠道、B3决定性线索、D1核查思路、D2查询经历、H1开放题 | 与信任分开记录，不将自报当成交易/浏览日志 |

C各维度、E、F均为3道自编题，至少有效2题才计算有效题均分，1–5高分含义依维度而定；9/拒答/无法判断与跳题不计0，保留缺失原因。不把行为题并入信任，不用绝对措辞要求“大品牌一定更好”。D1改为户外推荐与补涂条件的核查情境，无“备案标注易致痘”断言。G1“无法判断”单列，不当中间分。

## 四、方法与本周范围

1. **问卷设计（需求侧）**：候选版40个顶层题号，B2展开后44个变量；购买者最多40题号、仅使用者17题号。预计购买者8–10分钟，以预调研实测为准，不再称“28题/≤30题”。本轮不建平台、不发放、不生成冒充真实的回答。
2. **公开网数（供给侧）**：主源为**苏宁**（2026-10-30已确认）；京东仅作可选对照，不再“京东优先”。历史采集与字段见[03-数据采集字典](<03-数据采集字典.md>)与[真实商品数据目录](<数据/正式采集01-2026-10-30/>)。公开评价、社媒、注册核查取不到就留缺口，不越过登录/滑块，不虚构证据。
3. **轻量认知访谈（需另经人工许可）**：先5–8人试读关键概念，优先解决理解与路径，不强求额外8–10人长访谈。复杂联合分析、结构方程、聚类和随机实验不列为本周必需。
4. **题项属性**：全部自编待验证，不冒充成熟量表。若未来采用有出处量表，须逐题记录原文、来源、改编与适用性，另行审核。

## 五、抽样设计与样本量边界

- 现实为便利＋滚雪球抽样，记录招募渠道、筛选退出、购买/仅使用样本数和有效分析分母；不靠配额将其包装成概率抽样。
- **SRS教学参考**：在简单随机抽样、估计比例、95%置信水平、p=0.5、允许误差0.05等前提下，n=1.96²×0.25/0.05²≈384.16，向上取整385。**该计算不能保证本便利样本具有±5%误差或总体代表性**，不是本项目功效计算。
- 若仅以385为讨论用有效核心购买样本工作量、且有效率假设85%，约需454份完成问卷，旧“≥460”是粗略工作量余量；筛选通过率/购买者比例尚未知，不能将460次邀请保证换成385名购买者。实际正式规模待预调研可行性与人工确认，不为凑数填模拟样本。
- 可尝试多渠道触达，观察学生/职场、性别与敏感自报构成；原学生:职场6:4、性别1:1仅是触达参考，不设强制配额或代表性承诺。

## 六、预调研验收与数据质量

详见[候选问卷第三节](<06-问卷v1.1-预调研候选版.md>)，当前均为计划而非已通过：

- 先人工确认导语/隐私/有效联系方式和题项，再认知访谈5–8人；关键概念出现≥2人误解须修订复测。
- 路径测试覆盖同意、年龄、购买/使用、拒答与跳题，关键路径错误=0；导出与评分核对无误。
- 获许可后才预调研30–50份真人，尽量包含≥20名购买者及≥5名仅使用者；主要检查可理解与可执行，不用于验证假设。购买者时长中位数目标≤10分钟、90%≤15分钟；核心题无法判断/拒答>20%或单选项>80%触发复核而非自动删题。
- 逐维检查题项分布、题间与项目—其余题相关、α及可得不确定性；α约0.70仅作参考，非通过保证。小样本不能证明效度，不强做因子模型或以删题堆高α。
- 时长过短、同IP/设备、注意力题错误、长串同选/逻辑疑点只作标记；**时长或IP不得单独硬删**。经核实的技术重复保留一份；其他无效须人工结合至少两类独立证据、记录理由；争议样本保留并做含/不含敏感性对照。不新增个人身份追踪。
- 网数只采公开数据，保留URL、时间、原始存档；抽核价格、容量、参数/注册资料，区分标题宣称与已核实事实。

## 九、局限性

非概率、小范围、自报、横截面与自编量表均限制解释；注册/参数与价格不能单独证明产品总体质量或个体适用。单平台商品样本不代表市场全貌，需求侧也不得从供给侧直接推断。演练只求证据边界清楚、流程可复查，不扩展宏大模型、不用模拟结果证明假设。
