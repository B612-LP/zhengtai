# 01 市场调查概述：防晒霜消费中的审美焦虑与信息信任

## 一、选题背景（定性框架，试采数据到位后逐条补数）

1. **防晒从"夏季刚需"变为"全年刚需"**：防光老化教育普及，防晒使用场景全年化、日常化；深圳地处亚热带、日照强，本地感受更直接。
2. **两套信息体系并行且常常打架**：一边是"成分党"崛起（SPF/PA、化学/物理防晒剂、检测报告），一边是种草文化（博主测评、品牌软广），普通消费者夹在中间。
3. **监管信息门槛天然存在**：防晒属特殊化妆品，需注册（"国妆特字"），备案信息可在药监局公开查询——但多数消费者不知道、不会查。
4. **审美焦虑是防晒营销的核心杠杆**："美白""抗老""晒黑=不自律"等话术把防晒从功能品变成容貌管理品，焦虑情绪可能压过理性参数判断。

## 二、社会痛点（会议给定四点展开）

| 痛点 | 具体表现 | 对应研究环节 |
|---|---|---|
| 审美焦虑 | 晒黑焦虑、光老化恐惧、肤色白皙偏好 | 问卷 D 模块（焦虑简版量表）、H2 检验 |
| 专业信息理解门槛 | 看不懂 SPF/PA、成分表、检测报告 | 问卷 F 模块（理解门槛自评）、H3 检验 |
| 网络推荐影响 | 测评真假难辨、软广无标注、从众下单 | 问卷 B/C 模块（信息来源频率与信任） |
| 价格与品质认知偏差 | "贵=好""大牌=安全"，同参数不同价 | 问卷 G 模块、H4 检验 |

## 三、研究问题分解

- **总问题**：消费者购买防晒产品时，更相信专业参数，还是品牌宣传和社交媒体推荐？
- RQ1（信任结构）：消费者对①专业参数 ②品牌宣传 ③社媒推荐三类信息的信任度排序与人群构成如何？
- RQ2（影响因素）：审美焦虑、专业信息理解门槛、人群特征（性别/身份/肤质）如何改变信任结构？
- RQ3（行为结果）：信任结构如何影响实际购买（渠道、价格带、为宣传/参数支付的溢价意愿）？
- 附加 RQ4（供给侧真实度）：商品页宣称与药监局备案的一致性如何？（用公开数据可回答，做报告亮点）

## 四、调查目的与意义

- **描述**：摸清目标人群防晒信息信任的现状与结构。
- **解释**：检验焦虑与理解门槛对信任路径（中央 vs 边缘）的影响。
- **应用**：给消费者（如何查备案、识软广）、品牌（话术合规与信任建设）、平台/监管（软广标注治理）提供参考。
- **对队伍**：完整跑通"概述→设计→问卷→采集→分析→报告"全流程，逐章对照网考知识点（方法论演练优先，过程大于结果）。

## 五、核心概念界定（防歧义）

| 概念 | 本项目操作定义 |
|---|---|
| 专业参数 | SPF 值、PA 等级、成分类别（物理/化学/物化）、检测报告、备案注册信息 |
| 品牌宣传 | 品牌广告、专柜/主播讲解、包装话术（美白/抗老/清爽等宣称） |
| 社媒推荐 | 博主测评与种草、朋友/网友推荐、销量排行从众 |
| 审美焦虑 | 对晒黑、光老化、肤色外观的担忧与不安（简版量表测量，题项见 04） |
| 信任 vs 使用 | 信任＝态度层面（可信度评分）；使用＝行为层面（信息来源频率）；两者分开测，H1 靠缺口 |
