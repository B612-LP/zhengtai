# 03 数据采集字典 v1

> 四库结构：商品库（供给侧客观）、评价库（消费者公开反馈）、社媒库（推荐侧）、备案核验表（权威对照）。另有一手问卷数据（问卷平台导出，不入本字典）。

## 一、商品库 product_db（每行=1 个 SKU）

| 字段 | 类型 | 说明 |
|---|---|---|
| product_id | 文本 | 自编主键，如 PF0001 |
| brand / product_name | 文本 | 品牌 / 商品全名（照抄页面） |
| shop_type | 枚举 | 官方旗舰 / 品牌自营 / 专营店 / 代购 |
| price | 数值 | 页面售价（元），记录促销前/后 |
| spec | 数值 | 规格（ml 或 g） |
| unit_price | 数值 | 单价（元/ml），计算字段 |
| sales | 文本 | 页面销量口径（"已售1万+"照抄，不换算） |
| spf | 文本 | SPF 标称值（如 SPF50+） |
| pa | 文本 | PA 等级（PA+++ 等；无则记 NA） |
| ingredient_type | 枚举 | 物理 / 化学 / 物化结合 / 未标注 |
| claim_tags | 多值 | 宣称标签：美白 / 抗老 / 清爽 / 敏感肌友好 / 儿童 / 户外强防护 / 提亮… |
| reg_no | 文本 | 页面所示"国妆特字"注册号；无则 NA |
| reg_check_result | 枚举 | 一致 / 宣称超出备案 / 未查到 / 待核 |
| url / captured_at / archive_path | — | 来源链接 / 采集时间 / 原始存档（截图或 HTML）路径 |

## 二、评价库 review_db（每行=1 条公开评价）

| 字段 | 类型 | 说明 |
|---|---|---|
| product_id | 文本 | 外键 |
| rating | 枚举 | 星级（平台口径） |
| text | 文本 | 评价原文 |
| has_media | 布尔 | 是否带图/视频 |
| keyword_hits | 多值 | 参数 / 成分 / 美白 / 油腻 / 假白 / 搓泥 / 回购 / 过敏… |
| ai_candidate_label | 多值 | AI 标注候选话术分类（仅候选，人工抽检 ≥10% 后生效） |
| captured_at / url | — | 同上 |

## 三、社媒库 social_db（每行=1 篇公开笔记/视频）

| 字段 | 类型 | 说明 |
|---|---|---|
| platform | 枚举 | 小红书 / 抖音 / B站 |
| post_id / title | — | 笔记 id 与标题 |
| rhetoric_type | 枚举 | 专业测评 / 成分讲解 / 种草软文 / 避雷警示 / 剧情/情景广告 |
| likes / collects / comments | 数值 | 互动量（页面口径） |
| has_link | 布尔 | 是否挂商品链接 |
| published_at / captured_at | — | 发布与采集时间 |

## 四、备案核验表 reg_check（每行=1 个注册号）

| 字段 | 说明 |
|---|---|
| reg_no / reg_name / registrant | 注册号 / 备案名称 / 备案人（药监局查询结果照抄） |
| claim_scope | 备案核准的宣称范围 |
| matched_product_id | 对应商品库 product_id |
| discrepancy_note | 页面宣称与备案差异备注（RQ4 的核心产出） |
| checked_at / source_url | 核验时间与来源 |

## 五、合规与真实度规则（全员适用）

1. 只采**公开**数据；控制采集频率，不绕过登录墙与付费墙；本项目仅用于比赛学习。
2. 每条数据必须可回溯：URL＋采集时间戳＋原始存档三者齐备才算"采到了"。
3. AI 只做候选标注与清洗脚本，**标注规则人工定、抽检 ≥10%**；AI 不生成任何"原始数据"。
4. 关键字段（价格、SPF/PA、注册号）双人核验抽样，核验记录留痕。
