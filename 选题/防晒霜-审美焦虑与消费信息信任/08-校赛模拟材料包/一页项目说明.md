# 一页项目说明

| 项 | 内容 |
|---|---|
| **课题名称** | 防晒霜购买中的审美焦虑与消费信息信任——基于供给端公开数据与问卷调查的混合研究 |
| **研究对象** | 18–35 岁、近 6 个月内购买或使用过防晒产品的消费者（学生为主、年轻职场为辅）；供给端为电商平台防晒商品（SPF/PA、价格、宣称、店铺） |
| **现实问题** | 消费者面对"专业参数"与"品牌宣传/社媒推荐"两套冲突信息：备案可查但少有人查，焦虑话术放大非理性决策，价格与品质认知存在偏差 |
| **调查范围** | 需求端：深圳为主、线上扩散（目标有效样本 ≥385）；供给端：综合电商平台"防晒霜"搜索结果（首期 119 款真实商品） |
| **核心研究问题** | 消费者购买防晒产品时，更相信专业参数，还是品牌宣传和社交媒体推荐？ |
| **预期成果使用方** | ① 消费者（信息素养与防坑指南）② 品牌（合规沟通与差异化方向）③ 平台/监管（种草层软广标注治理）④ 队伍（全流程方法论演练作品） |
| **当前状态** | 供给端真实数据分析完成；需求端问卷终稿就绪、11-08 起回收（现版报告以标注隔离的模拟数据演示链路） |
