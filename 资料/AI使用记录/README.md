# AI 使用记录

> 建立日期：2026-10-27。依据：当日会议明确要求现在就建独立文件夹，记录 AI 参与范围，区分人的想法、AI 生成内容及人工修改。

## 用法

每次有实质用途时记录，不必保存无关闲聊；如比赛要求关键交互原文，再保留脱敏导出或截图。本目录是内部记录模板，不代表官方指定格式；提交前须核对本届 AI 使用规范。

| 字段 | 要写清楚什么 |
|---|---|
| 日期、工具、模型/版本 | 能确认多少写多少，不知道就注明未知 |
| 人工原始输入/想法 | 哪些问题、原始材料和判断来自人，来源编号是什么 |
| AI 任务与输出 | 整理、代码、标签、图表还是建议；对应文件与版本 |
| 数据范围 | 是否含真实调查数据，是否脱敏，是否获准输入外部服务 |
| 人工审核与修改 | 审核人、核验项目、修改内容；未审核就明确标注 |
| 采用状态 | 未采用、待审、用于测试、进入正式分析/报告 |
| 证据与限制 | 交互记录位置、来源缺口、AI 不应替代的责任 |

原始材料与 AI 摘要分开；AI 提出的候选结论、测试样本不能冒充调查发现。不得记录凭据、无关个人信息或未获准外传的原始资料。
