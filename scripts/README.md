# 仓库质量检查器

检查器仅使用 Python 3 标准库及本机 Git，全程离线、只读，不运行研究、采集或生成脚本，不自动修复、不暂存、不提交。单元测试会在系统临时目录构造并清理测试仓库，不修改项目研究文件。

## 运行

在仓库根目录执行：

```sh
python3 scripts/check_repo.py
python3 -m unittest discover -s tests -v
```

从任意临时目录也可使用检查器的绝对路径；默认检查脚本所在仓库，不依赖当前目录。可用 `--root /待检查的仓库根目录` 检查另一 Git 仓库。

退出码：存在 `error` 返回 **1**；没有错误或只有 `warning` 返回 **0**。Git 不可用、根目录无效或文件读取失败均返回 1。诊断输出包含规则名、相对路径，坏链包含 Markdown 行号。

## 检查范围与规则

- 文件清单：`git ls-files -z --cached --others --exclude-standard`，包含未忽略的新文件；已经被 Git 跟踪的 ignored 文件仍检查。未暂存删除的跟踪文件作为 `missing-file` 报错。Git 子模块内容不递归检查。
- Markdown：检查 `.md` / `.markdown` 的行内链接、图片目标及引用定义。支持中文、`<含空格路径>`、URL 编码、相对路径、平衡括号/反斜线转义、可选标题、目录和片段。只检查路径存在，**不验证片段对应的标题**。查询参数和片段在 URL 解码前去除；以 `/` 开头的本地链接以仓库根目录为基准。
- 不检查外部协议（包括 `http`、`https`、`mailto`、`data` 等）、`//host` 网络路径、空目标、纯锚。屏蔽反引号/波浪线围栏、缩进代码、任意长度反引号行内代码及 HTML 注释；支持引用块内代码。引用目标在定义处只检查一次；不把没有定义的普通方括号文字当作链接。
- 敏感文件名：`.env`、`.env.*`（仅精确允许 `.env.example` / `.env.sample`）、`id_rsa` / `id_dsa` / `id_ecdsa` / `id_ed25519` / `identity`、`.key` / `.p12` / `.pfx`。SSH `.pub` 公钥、普通 `.pem` 证书不因扩展名报错；其内容仍接受扫描。示例环境文件也不会豁免内容扫描。
- 高置信内容：GitHub 经典 token（`ghp` / `gho` / `ghu` / `ghs` / `ghr` 前缀及精确长度）与细粒度 PAT；匹配 BEGIN/END 类型及 Base64 正文的 PEM 私钥（含 RSA、EC、DSA、OpenSSH、加密格式及传统加密 RSA 头）。短占位符、独立 PEM 说明标记与公钥不误报。
- 对所有普通文件分块扫描，包括二进制文件；重叠区捕获跨块 token，跨块 PEM 支持至 64 KiB。诊断不打印秘密值，并对文件名/坏链目标中的 token 再次脱敏。
- 大文件：**严格大于 20 MiB** 为 warning；**严格大于 100 MiB** 为 error（1 MiB = 1024² 字节）。恰好 20 MiB 不报，恰好 100 MiB 为 warning。
- 不跟随 Git 清单中的符号链接读取内容，以免扫描仓库外的私人文件；断开的符号链接报错。本地 Markdown 目标可以是存在的符号链接。

## 边界

这是保守的本地存在性与高置信凭据检查，不是完整 CommonMark 渲染器或通用秘密审计工具。不解析原始 HTML 的 `href`、不验证网络链接，不承诺识别所有 Markdown 扩展语法、所有凭据类型或超长跨块私钥。文件名规则不区分大小写，可能将确实公开的 `.key` / `.p12` / `.pfx` 样例报错，需人工确认，不能以此工具替代发布前审查。

测试使用临时 Git 仓库，覆盖文件清单、中文链接、目录、片段、代码排除、敏感文件名/内容、跨块扫描、大小阈值、脱敏、错误退出和从临时工作目录启动。
